# Listing Quality Scorecard

Use this scorecard to audit any Home Depot listing — Calwood or a competitor. Run monthly for top Calwood SKUs. Run any time a listing is underperforming or a new SKU is being set up.

Score each dimension 1–5:
- **1** = Missing or very poor
- **2** = Present but significantly below standard
- **3** = Acceptable — meets minimum bar
- **4** = Good — above average
- **5** = Excellent — best-in-category

Label confirmed data sources where possible.
