# Dispute Template: Customer Choice + Destroy for Credit Defective

## When to use this template

Use this template when an RTV record shows **both** of the following:

- **Return Reason:** Customer Choice (or equivalent — customer preference, customer error, wrong item ordered, changed mind)
- **Disposal Code:** Destroy for Credit Defective (or equivalent — DFC, destroy defective, DFC credit)

This combination is a direct contradiction. A customer preference return does not constitute a manufacturing defect. Destruction authorization under a defect code requires a documented defect. If no defect was photographed, inspected, or reported, Calwood should not be charged.

## When NOT to use this template

Do not use this template if:

- Home Depot or the store has provided defect photos, inspection notes, or a written customer complaint describing a product failure
- The product was genuinely defective and Calwood is aware of it
- The return reason is Manufacturer Defect (use the manufacturer-defect-no-proof template instead)
- The disposal code is standard return, not destroy/defective

## Evidence Checklist

Gather these before submitting. Check off each item confirmed.

- [ ] RTV notice from Home Depot (showing both reason code and disposal code)
- [ ] Original PO or order confirmation
- [ ] Tracking number and carrier name
- [ ] Proof of delivery (POD) — signed delivery confirmation
- [ ] Delivery date confirmed
- [ ] No noted damage or defect on POD
- [ ] No defect photos from Home Depot or the store
- [ ] No inspection notes from Home Depot or the store
- [ ] No written customer complaint describing a product failure

**Strong case:** All boxes checked. Submit immediately.
**Medium case:** POD missing or delivery date unclear. Request POD from carrier before submitting.
**Do not submit:** If defect photos or inspection notes exist and show a real product failure.

## Notes

- The longer the gap between delivery and RTV initiation, the stronger the argument that no defect existed at time of delivery.
- If the store associate signed the POD without noting damage, that is evidence in Calwood's favor.
- Always attach the RTV notice itself — it is the document that shows both the contradictory codes.
- If Home Depot responds with defect photos, evaluate whether the defect is a real manufacturing issue or normal wood character (grain variation, natural color variation, knots) that was misidentified as defective.
