# Dispute Template: Manufacturer Defect — No Supporting Proof

## When to use this template

Use this template when an RTV or deduction lists the return reason as **Manufacturer Defect** (or equivalent — product defect, defective merchandise, vendor defect) but Home Depot has not provided any of the following:

- Defect photos
- Inspection notes from the store or returns center
- A written customer complaint describing the specific failure
- A third-party inspection report

A defect allegation is not proof of a defect. Calwood should not issue credit for an alleged defect that has not been documented. This template challenges the deduction and requests the documentation required to evaluate the claim.

## When NOT to use this template

Do not use this template if:

- Home Depot has provided clear defect photos showing a genuine manufacturing failure (wrong finish, delamination, cracking under normal conditions, structural failure)
- Calwood is aware of a quality issue with the specific lot or batch
- The customer complaint is specific, credible, and consistent with a manufacturing failure Calwood has seen before
- The product was returned in a condition that clearly indicates a defect (use your judgment; if the evidence is there, evaluate whether to accept)

## Evidence Checklist

Gather these before submitting.

- [ ] RTV notice showing Manufacturer Defect as the return reason
- [ ] Original PO or order confirmation
- [ ] Tracking number and carrier name
- [ ] Proof of delivery (POD) — confirmed delivery with no noted damage
- [ ] Confirmation that no defect photos were provided by Home Depot
- [ ] Confirmation that no inspection notes were provided
- [ ] Confirmation that no specific customer complaint was provided
- [ ] Lot number or batch ID for the product if available (useful if Home Depot later claims a lot-level defect)

**Strong case:** Return reason is Manufacturer Defect, zero documentation provided, product was delivered without noted damage. Submit immediately.
**Medium case:** Home Depot provided a vague or general defect description without photos. Submit but acknowledge the description and request specifics.
**Do not submit:** If clear defect photos show a genuine manufacturing failure.

## Notes

- Wood products are frequently returned for characteristics that are natural and not defects: color variation, grain pattern, knots in character-grade material, or natural texture variation. If Home Depot eventually provides photos, evaluate whether what they are calling a defect is actually within normal wood character for the grade sold.
- If Calwood sold a rustic or character-grade product, include the grade specification in your response so Home Depot knows what was represented at point of sale.
- If Home Depot provides a vague complaint like "customer said it looked different than expected," that is a Customer Choice return mislabeled as Manufacturer Defect — switch to the customer-choice-destroy-for-credit-defective template logic.
- Always note the gap between delivery date and RTV initiation date. A 3-week gap with no defect report weakens Home Depot's claim significantly.
