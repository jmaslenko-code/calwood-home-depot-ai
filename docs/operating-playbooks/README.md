# Docs: Operating Playbooks

Step-by-step process documentation for running Calwood's Home Depot channel operations.

## What belongs here

- End-to-end process playbooks for each operational area (disputes, freight audits, QuoteCenter, Rithum, Pro Desk)
- Onboarding guides for new team members covering HD-specific workflows
- Escalation paths and contact directories (buyer contacts, AP contacts, carrier reps)
- Compliance requirement summaries (vendor standards, routing guides, labeling rules)
- Decision trees for common edge cases (e.g., when to escalate vs. write off a dispute)

## Naming convention

`[area]-playbook-[version].md`
Example: `disputes-playbook-v1.md`, `rithum-fulfillment-playbook-v2.md`
