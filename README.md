# Calwood Home Depot AI

This repository supports **Calwood Flooring Supply's Home Depot channel growth** across all touchpoints and operational workflows.

## Scope

- **HomeDepot.com** — product listings, content optimization, and catalog management
- **Rithum / CommerceHub** — EDI order routing, fulfillment feeds, and integration monitoring
- **QuoteCenter** — special pricing, bid management, and quote workflows
- **Special Order** — custom product sourcing, lead times, and order tracking
- **Pro Desk Outreach** — contractor and trade customer engagement, store-level relationship building
- **Disputes** — invoice dispute resolution, chargeback management, and compliance
- **Freight Billing** — freight audit, carrier reconciliation, and billing corrections
- **SKU Strategy** — assortment planning, item setup, and product lifecycle management
- **Competitor Intelligence** — pricing, assortment, and positioning analysis vs. competing suppliers

## Repository Structure

```
skills/                         # AI agent skills for automated workflows
  calwood-hd-competitive-intel/ # Competitor pricing and assortment monitoring
  calwood-hd-disputes-freight-auditor/ # Dispute and freight billing automation

templates/                      # Reusable document and communication templates
  dispute-letters/              # Formal dispute and chargeback letter templates
  store-outreach/               # Pro Desk and store-level outreach templates
  rithum-analysis/              # CommerceHub/Rithum reporting and analysis templates
  quote-center/                 # QuoteCenter bid and pricing templates

docs/                           # Operating documentation and review materials
  operating-playbooks/          # Step-by-step process playbooks
  weekly-review/                # Weekly channel review templates and archives

scripts/                        # Automation and reporting scripts
  data-cleaning/                # Data normalization and preparation scripts
  reporting/                    # Channel performance reporting scripts
```
