# Skill: Calwood HD Disputes & Freight Auditor

AI skill for automating the review, classification, and drafting of dispute responses and freight billing corrections.

## What belongs here

- Skill definition files (skill configuration, prompts, tool definitions)
- Dispute classification logic (chargeback type, root cause, dollar threshold)
- Freight invoice audit rules and carrier rate comparison logic
- Draft generation prompts for dispute letters and billing correction requests
- Case tracking templates and resolution workflow definitions

## Intended use

This skill processes Home Depot dispute notifications and freight invoices, classifies them by type and priority, cross-references against purchase orders and shipment records, and generates ready-to-send dispute letters or freight correction requests. It reduces manual review time and ensures consistent, policy-compliant responses.
